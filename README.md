# Классификатор обращений в поддержку

Сервис на FastAPI, который с помощью LLM (Google Gemini, structured output) определяет у обращения клиента категорию, срочность и пишет краткое резюме. Качество измерено на собственном eval-наборе из 42 примеров (`evals/dataset.jsonl`, из них 18 сложных).

| Эндпоинт | Метод | Что делает |
| --- | --- | --- |
| `/health` | GET | `{"status": "ok"}` |
| `/classify` | POST | `{"text": "..."}` → `{"category", "urgency", "summary"}` |
| `/classify/batch` | POST | `{"texts": [...]}` (1–50 штук) → `{"results": [...]}`, запросы к модели идут параллельно |

Swagger: <http://localhost:8000/docs>.

## Установка и запуск

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/) и API-ключ Gemini (<https://aistudio.google.com/apikey>, бесплатного тарифа хватает).

```bash
cp .env.example .env    # затем впишите ключ в GEMINI_API_KEY
uv sync
uv run uvicorn app.main:app
```

Проверка:

```bash
curl localhost:8000/health
curl -X POST localhost:8000/classify -H 'Content-Type: application/json' \
  -d '{"text": "Не приходит код из SMS, третий день не могу войти в приложение"}'
```

Через Docker (после `cp .env.example .env` с ключом):

```bash
docker compose up --build
```

Настройки (`.env`, пустые значения = значения по умолчанию из `app/config.py`): `GEMINI_MODEL` (по умолчанию `gemini-3.5-flash-lite`), `TEMPERATURE` (от 0 до 2, по умолчанию 0), `MAX_RETRIES` (не меньше 1, по умолчанию 3), `BATCH_CONCURRENCY` (не меньше 1, по умолчанию 5), `PROMPT_PATH` (по умолчанию `prompts/classify.md`), `REQUEST_TIMEOUT_S` (таймаут одного запроса к модели в секундах, больше 0, по умолчанию 30). Значение вне диапазона останавливает запуск с ошибкой, в которой названо поле.

Тесты и линтер (модель в тестах замокана, реальных вызовов нет):

```bash
uv run pytest
uv run ruff check .
```

### Eval

```bash
MAX_RETRIES=7 uv run python -m evals.run_eval --prompt prompts/versions/v3.md --model gemini-3.5-flash-lite
```

Скрипт сначала проверяет набор (`uv run python -m evals.validate_dataset`), затем печатает accuracy, матрицу ошибок и список ошибок и сохраняет прогон в `evals/results/<дата-время>.json` (модель, temperature, хэши промпта и набора, метрики, ответы по каждой строке, время, токены).

`MAX_RETRIES=7` нужен на бесплатном тарифе: у gemini-3.5-flash-lite лимит 15 запросов в минуту, и с 3 попытками часть строк падает с 429. С 7 попытками экспоненциальная задержка (1, 2, 4… с) пережидает минутное окно. Строка, на которой модель так и не ответила, сохраняется с полем `error` и считается ошибкой во всех метриках.

## Модель и провайдер

**Провайдер — Google Gemini** через SDK `google-genai`:
- бесплатного тарифа хватает на все прогоны (реальная стоимость всех прогонов — $0);
- structured output: схема ответа передаётся как `response_schema=ModelOutput` (Pydantic-модель), `category` и `urgency` — Enum, парсинга регулярками нет;
- temperature 0, как рекомендует задание.

**Модель — `gemini-3.5-flash-lite`, и в сервисе по умолчанию (`gemini_model` в `app/config.py`), и в eval.** Все итерации промпта прогонялись на ней, и все метрики ниже относятся к ней. Причина — лимиты бесплатного тарифа: прогон набора — это 42 запроса, а у gemini-3.5-flash и gemini-3.6-flash на бесплатном тарифе лимит 20 запросов в день (в ошибке квоты для обеих указана модель gemini-3.6-flash; `GenerateRequestsPerDayPerProjectPerModel-FreeTier`, `quotaValue: 20` в `2026-11-02_17-45-49.json` и `2026-11-02_18-29-23.json`). У gemini-3.5-flash-lite лимит 15 запросов в минуту (`quotaValue: 15` в `2026-11-02_17-51-14.json`), его можно переждать ретраями.

**Альтернатива — `gemini-3.5-flash`** (`GEMINI_MODEL=gemini-3.5-flash` в `.env`). При ручной проверке `/classify` (коммит `e68bcb7`) `gemini-3.8-flash` и `gemini-3.7-flash` на бесплатном ключе отвечали 504 DEADLINE_EXCEEDED, а `gemini-3.5-flash` ответила примерно за 2,5 с. Но на eval-наборе она не измерена (см. выше), а на бесплатном тарифе ей доступно только 20 запросов в день, поэтому по умолчанию стоит измеренная `gemini-3.5-flash-lite`.

## Сравнение моделей

Оба прогона: финальный промпт v3 (хэш `dc8529b602a2`), тот же набор (хэш `de3da1692a4c`), temperature 0. Команда: `MAX_RETRIES=7 uv run python -m evals.run_eval --model <модель>` (прогон gemini-3.5-flash-lite запускался с `--prompt prompts/versions/v3.md`, хэш тот же).

| | gemini-3.5-flash-lite | gemini-3.1-flash-lite |
| --- | --- | --- |
| Файл результата | `2026-11-02_18-15-17.json` | `2026-11-02_19-17-16.json` |
| accuracy по category | 41/42 (97.6%) | 42/42 (100.0%) |
| accuracy по urgency | 33/42 (78.6%) | 31/42 (73.8%) |
| сложные, category | 17/18 (94.4%) | 18/18 (100.0%) |
| сложные, urgency | 14/18 (77.8%) | 12/18 (66.7%) |
| Упавших запросов | 0 | 0 |
| Среднее время на строку, с | 2.72 | 5.62 |
| Медианное время на строку, с | 0.88 | 3.64 |
| Входные токены (42 строки) | 17 465 | 17 465 |
| Выходные токены (42 строки, thinking-токенов нет) | 1 564 | 1 484 |
| Цена, вход / выход за 1M токенов | $0.30 / $2.50 | $0.25 / $1.50 |
| Оценка стоимости, 42 строки | $0.0091 | $0.0066 |
| Оценка стоимости на 1000 запросов | $0.22 | $0.16 |

- **Стоимость** = входные токены × цена входа + выходные токены × цена выхода, по ценам платного тарифа Standard с <https://ai.google.dev/gemini-api/docs/pricing> (страница «Last updated 2026-10-30 UTC», проверено 2026-11-02). Сами прогоны шли на бесплатном тарифе («Free of charge» для обеих моделей), поэтому реально они стоили $0.
- **Время** — полное время на строку, включая ожидание ретраев. Классификатор повторяет запросы при 429 (лимит бесплатного тарифа, 15 запросов в минуту для gemini-3.5-flash-lite) и 503; gemini-3.1-flash-lite перед своим прогоном ответила на пробный запрос 503 «high demand». Самые медленные строки (максимум 37.9 с и 39.0 с), скорее всего, ждали ретраев, а не модель; ретраи в файлах результатов не записываются, так что это не проверено. Поэтому приведена и медиана — она меньше зависит от этих ожиданий.
- Обрезанных резюме (`summaries_trimmed`): 0 в обоих прогонах.

**Почему эти две модели.** По плану сравнивались Flash и Flash-Lite, но на бесплатном тарифе это невозможно:
- `gemini-3.6-flash`: 20 запросов в день на модель (`GenerateRequestsPerDayPerProjectPerModel-FreeTier`, `quotaValue: 20`), а на набор нужно 42. Попытка сохранена как невалидный прогон `2026-11-02_18-29-23.json` (41 из 42 запросов упали с 429).
- `gemini-3.8-flash`: 2026-11-02 ответила на единственный пробный запрос 503 «high demand» (раньше на этом ключе отдавала 504).

Поэтому сравниваются два поколения Flash-Lite из текущего списка моделей (<https://ai.google.dev/gemini-api/docs/models>, «Last updated 2026-10-28 UTC», проверено 2026-11-02): более новая gemini-3.5-flash-lite (на ней шли итерации промпта) и более старая и дешёвая gemini-3.1-flash-lite. Обе стабильные, доступны на бесплатном тарифе и в каждой строке вернули валидный structured output.
